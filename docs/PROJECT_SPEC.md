# 단국대학교 데이터지식서비스공학과 홈페이지 프로젝트 명세

## 목적
단국대학교 일반대학원 데이터지식서비스공학과의 교육·연구 정체성을 명확히 전달하고, 공지·논문·사진·학과 내규·입학안내·공유 자료로 빠르게 이동할 수 있는 반응형 공식 홈페이지를 운영한다.

## 핵심 사용자
- 입학 및 연구 분야를 탐색하는 예비 대학원생
- 공지, 논문, 사진, 내규, 자료를 확인하는 재학생과 연구자
- 모집요강과 박사과정 사전 컨택 절차를 확인하는 지원자
- 인증 후 공지사항·논문·모집요강·사진 앨범을 등록·수정·삭제하는 홈페이지 관리자

## 핵심 기능
- 학과 소개, 공지사항, 논문, 학과 내규, 입학안내·모집요강 라우트
- 공지사항·논문(학술대회·저널)·입학안내·모집요강의 공개 조회와 활성 관리자에게만 허용되는 등록·수정·삭제
- `/photos` 공개 사진 앨범 목록과 `/photos/:id` 상세 슬라이더·조회수·이전글·다음글·다운로드
- 공개 사진 표시 응답·개별 다운로드·앨범 전체 ZIP 다운로드와 활성 관리자 전용 앨범 등록·정보 수정·이미지 추가·순서 변경·삭제
- `/admin` 관리자 로그인과 관리자 계정·콘텐츠 관리 진입 경로
- 활성 관리자 전용 공지 첨부 업로드와 공개 첨부 다운로드
- 종료 상태를 유지하는 논문 댓글
- Google Drive 공유 자료실 연결

## 홈페이지 요구사항
- 단국대학교 공식 로고와 죽전캠퍼스 이미지를 첫 화면에서 식별할 수 있어야 한다.
- 메인 메시지는 “데이터로 지식을 만들고, 미래를 설계합니다”를 사용한다.
- 첫 화면에 “학과 소개 보기”와 “입학안내” 행동 버튼을 제공한다.
- 최신 공지와 자료실을 동일한 위계의 2열 목록으로 제공하고, 자료 메뉴에서 내부 사진자료실과 외부 Google Drive 공유자료실을 구분한다.
- 학과 소개에는 별도 개인정보 입력 없이 이메일로 문의하는 박사과정 사전 컨택 절차를 제공한다.
- 입학안내에는 최신 게시일 우선 모집요강 목록, 전체·제목·내용·게시기관 검색, 조회수와 선택적 HTTPS 첨부 링크를 제공한다.
- 홈 바로가기와 모바일 상단 메뉴에서 내부 화면을 선택하면 대상 경로의 최상단으로 이동해야 한다. 이미 열린 경로를 다시 선택한 경우에도 같은 기준을 적용한다.
- 모바일 메뉴에서 사진자료실을 선택하면 내부 `/photos`로 이동하고, 공유자료실을 선택하면 승인된 Google Drive 주소를 새 탭으로 연다.
- 모바일 0–767px, 태블릿 768–1023px, 데스크톱 1024px 이상에서 탐색과 읽기가 가능해야 한다.

## 비기능 요구사항
- TypeScript 검사와 프로덕션 빌드를 통과해야 한다.
- 이미지에는 대체 텍스트를 제공하고 키보드 탐색이 가능해야 하며, 사진 슬라이더는 일시정지와 동작 감소 설정을 지원해야 한다.
- 소셜 미리보기에는 Replit 자산을 사용하지 않고 단국대학교 브랜드 자산을 사용한다.
- 공지사항·논문·모집요강·사진자료실의 관리 쓰기는 활성 관리자 권한, 동일 출처 검사, 입력 검증과 IP 기반 속도 제한을 모두 통과해야 한다.
- 공지 첨부 업로드는 활성 관리자에게만 허용하고, 허용 확장자·MIME·파일 시그니처, 최대 5개·파일당 10MB 제한을 적용한다.
- 사진 업로드는 JPEG·PNG·WebP만 허용하며 요청당 최대 12개·입력 파일당 8MB로 제한한다. 서버에서 방향을 보정하고 최대 2000×1500 WebP로 최적화하며 결과 파일당 3MB, 앨범당 30MB를 넘기지 않는다.
- 최적화된 사진 데이터와 메타데이터는 기존 Neon PostgreSQL의 `BYTEA`와 관계형 테이블에 저장한다. Render 로컬 파일시스템을 사진 영구 저장소로 사용하지 않는다.
- 관리자 비밀번호는 서버 측 salted scrypt 해시로만 검증하고, 세션은 PostgreSQL과 보안 쿠키로 관리한다.
- 환경 관리자 계정값과 비밀번호 해시는 Render Secret에서 관리하며 소스, 문서, 클라이언트 번들과 로그에 기록하지 않는다.
- 최초 활성 관리자가 없는 경우에만 일회성 설정 절차를 제공한다. 활성화가 끝난 뒤 일반 로그인 화면은 관리자 아이디와 마스킹된 비밀번호만 입력받는다.
- 공개 회원가입, 인재풀 등록과 방문자 개인정보 입력 기능은 복원하지 않는다.

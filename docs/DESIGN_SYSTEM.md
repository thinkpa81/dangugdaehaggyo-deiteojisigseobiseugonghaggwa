# 디자인 시스템

## 원칙
성균관대학교 기술경영전문대학원 사이트의 정보 구조와 공공 교육기관다운 밀도를 참고하되, 문구·브랜드·콘텐츠는 단국대학교 데이터지식서비스공학과 고유 자산만 사용한다.

## 색상
| 토큰 | 값 | 용도 |
| --- | --- | --- |
| Primary | `#2156D9` | 주요 버튼, 링크, 강조 |
| Navy | `#0B2B50` | 헤더 강조, 빠른 메뉴, 푸터 |
| Ink | `#0F172A` | 제목과 본문 핵심 텍스트 |
| Muted | `#64748B` | 보조 텍스트 |
| Surface | `#F8FAFC` | 구획 배경 |
| Accent | `#F4A000` | 제한적 포인트 |

## 타이포그래피
- 기본: Pretendard → Noto Sans KR → 시스템 산세리프
- 본문: 15–18px, 행간 1.55–1.75
- 섹션 제목: 30–40px, 굵기 800–900
- 메인 제목: 320–639px에서 31–35px 유동 크기, 640px 이상 48–58px, 굵기 900, 모바일 자간 -0.055em

## 공간과 형태
- 기본 간격 단위: 4px
- 버튼 모서리: 6px
- 카드 모서리: 10px
- 본문 최대 폭: 1200px
- 그림자: 낮은 대비로 제한하고, 정보 구분은 여백과 경계선을 우선한다.

## 반응형
- 모바일: 0–767px, 1열과 슬라이드 메뉴
- 태블릿: 768–1023px, 2–3열 보조 구조
- 데스크톱: 1024px 이상, 최대 폭 1200px

## 접근성
- 배경 이미지 위 텍스트는 짙은 오버레이로 명암비를 확보한다.
- 메인 히어로의 핵심 안내 문구는 별도 테두리·표면 없이 흰색 본문과 Accent 핵심어, 짙은 텍스트 그림자로 배경 이미지와 분리한다.
- 아이콘만 있는 버튼에는 접근 가능한 이름을 제공한다.
- 사용자의 `prefers-reduced-motion` 설정을 존중한다.
- 키보드 포커스는 브라우저와 UI 컴포넌트의 가시적 포커스 스타일을 유지한다.

## 내부 페이지 히어로
- 학과 소개·공지사항·학과 내규·논문·입학안내는 `PageHero`를 공통 사용한다.
- 높이는 모바일 최소 260px, 데스크톱 최소 300px로 유지한다.
- 사용자 제공 이미지는 `object-fit: cover`로 배치하고 피사체에 맞게 페이지별 `object-position`만 조정한다.
- 단색 Navy 오버레이를 적용해 제목·설명의 명암비와 학과 브랜드 일관성을 유지한다.

## 지도교수 프로필
- 지도교수·연구분야는 최대 1440px 래퍼의 단일 카드로 구성하고, 박사과정 컨택 안내는 같은 폭의 독립 카드로 바로 아래에 배치한다.
- 1280px 이상은 왼쪽 336px 사진 전용 패널과 오른쪽 유동형 정보·연구 패널로 나누고 카드 높이는 콘텐츠에 맞춰 자연스럽게 결정해 연구카드 아래 여백을 과도하게 늘리지 않는다. 1024–1279px은 왼쪽 280px, 768–1023px은 왼쪽 240px을 사용한다.
- 연구카드는 1024px 이상에서 `4·4·2`, 768–1023px에서 2열, 767px 이하에서 1열로 전환해 긴 영문 항목이 잘리지 않도록 한다.
- 767px 이하는 사진 패널 → 교수 정보·연구분야 → 박사과정 컨택 순서의 완전한 1열로 전환한다.
- 학과 소개 히어로 바로 아래에 배치해 지도교수 정보를 먼저 제시하고, 학과 개요·전공 소개·교과과정이 이어지도록 한다.
- 연구관심분야는 데스크톱 상단 4열 2행으로 구성하고 마지막 2개 항목은 각각 2열을 차지하는 대형 셀로 표시한다. 태블릿은 2열, 모바일은 1열로 전환한다.
- 좌측 연청색 패널에는 원형 사진만 배치하고, 우측 흰색 패널에는 `지도교수`·교수명 → 소속·AIMS Lab → 연구관심분야 순서를 유지한다.
- 교수 사진은 원형 보라–분홍 테두리 자산과 `서응교 지도교수` 대체텍스트를 사용한다. 컨택 수신 행의 교수 이메일과 전송 링크는 모두 가시적 포커스를 갖춘 `mailto:`로 제공하고 긴 주소는 카드 안에서 줄바꿈한다.
- 박사과정 컨택은 표준 졸업모 선형 아이콘으로 프로그램 성격을 보조하고, 단계·목록 번호 없이 `이메일 문의`와 `기타 문의` 두 소제목으로 구성한다. 본문은 17–19px 범위와 넉넉한 행간을 사용하며, 359px 이하에서는 아이콘·영문 머리말 첫 행과 한글 제목 다음 행의 2행 헤더로 전환한다.

## 논문 분류와 등록
- 논문 분류는 `학술대회`와 `저널` 두 항목만 노출한다. 기존 국내·해외·본 심사 분류 데이터는 해당 상위 분류에 포함해 표시한다.
- 공개 방문자는 두 분류의 목록·상세만 조회하며, 활성 관리자 세션에서만 등록·수정·삭제 조작을 표시한다.
- 관리자 등록·수정 창의 사용자 입력은 논문 제목, 저자, 사이트 주소 세 항목으로 제한한다.
- 사이트 주소는 `http://` 또는 `https://` 형식을 검증하며, 발행연도·등록일·조회수 등 시스템 필드는 자동 저장한다.
- 논문 댓글 수, 댓글 목록과 댓글 작성·수정·삭제 UI는 제공하지 않으며 기존 댓글 데이터는 삭제하지 않고 서버 API만 종료 상태로 유지한다.

## 대학원 정보 화면의 아이콘 원칙
- 장식 목적의 이모지는 사용하지 않고, 문서·조회·이동 등 기능을 설명하는 표준 선형 아이콘만 제한적으로 사용한다.
- 학과 내규는 장 번호와 제목을 중심으로 구성하며, 논문과 공지사항의 첨부파일은 동일한 문서 아이콘을 사용한다.
- 반복 목록에서는 장식용 아이콘 박스를 제거해 제목, 저자, 조회수 등 핵심 정보의 위계를 우선한다.

## 조회수 표시
- 논문 목록과 상세 화면에는 발행연도 대신 `조회수 N`을 표시한다.
- 조회수는 상세 화면을 열 때마다 서버에서 원자적으로 1 증가하며, 응답 이후 목록과 상세 화면을 최신 값으로 동기화한다.

## 입학안내·모집요강
- 데스크톱은 230px 좌측 메뉴와 유동형 목록의 2열 구조, 모바일은 메뉴와 목록의 1열 구조를 사용한다.
- 목록은 제목, 게시 기관, 날짜, 조회수와 선택적 HTTPS 첨부 링크를 표시한다.
- 검색은 `제목+내용`·`제목`·`내용` 범위의 실제 선택 요소, 검색어 입력과 제출 버튼을 하나의 `form`으로 구성해 Enter와 키보드 탐색을 지원한다.
- 검색어는 제출 시 앞뒤 공백을 제거하고 한글·영문 대소문자 검색을 지원하며, 결과 수·빈 상태·로딩·오류를 보조기기에 알린다.
- 모집요강 목록·상세·검색과 조회수 증가는 공개하되 등록·수정·삭제 조작은 활성 관리자 세션에서만 표시한다. 이름·연락처 등 개인정보 입력이나 동의 UI는 두지 않는다.
- 학과 소개의 지도교수·연구 패널 바로 아래에는 같은 전체 폭의 박사과정 컨택 안내를 배치하고 이메일 문의 방식만 제공한다.

## 사진자료실
- 사진자료실은 최대 1200px 본문 폭에서 단국대학교 브랜드 색상과 공공 교육기관형 정보 밀도를 유지한다. 사진 자체가 중심이 되도록 카드 그림자보다 여백·경계선·텍스트 위계를 우선한다.
- 목록은 데스크톱에서 3열, 800px 이하에서 2열로 전환한다. 대표 이미지는 카드마다 동일한 비율과 `object-fit: cover`를 적용하고, 제목은 두 줄 안에서 식별할 수 있게 하며 게시일·조회수·사진 수는 보조 정보로 배치한다. 게시기관과 본문은 상세 화면에 배치한다.
- 목록 검색은 검색 범위 선택, 검색어 입력과 제출 버튼을 하나의 `form`으로 구성한다. 로딩·오류·결과 없음·검색 결과 수와 페이지 상태는 화면과 보조기기 모두에 전달한다.
- 상세는 제목·게시기관·조회수·게시일 다음에 4:3 주 이미지를 배치한다. 이전·다음 화살표, 현재 위치, 썸네일과 자동 재생 일시정지를 함께 제공하되 작은 화면에서는 주 이미지와 핵심 조작을 우선한다.
- 썸네일은 실제 버튼으로 만들고 현재 사진에 `aria-current` 상태를 제공한다. 모든 사진은 앨범 제목과 순서를 반영한 설명형 대체텍스트를 사용하며 화살표·관리 조작에는 접근 가능한 이름과 가시적 포커스를 제공한다.
- 자동 재생은 사용자가 일시정지할 수 있어야 하며 `prefers-reduced-motion`이 활성화된 환경에서는 자동 전환하지 않는다. 키보드 이전·다음 탐색과 터치 환경의 직접 선택을 지원한다.
- 상세 하단은 앨범 설명, 전체 ZIP·개별 이미지 다운로드, 이전글·다음글·목록 이동 순서를 사용한다. 다운로드 조작은 파일명과 용도를 텍스트로 구분한다.
- 등록·정보 수정·이미지 추가·순서 변경·이미지 삭제·앨범 삭제 조작은 관리자 세션에서만 표시한다. 파일 선택 단계에서 JPEG·PNG·WebP, 최대 12개와 파일당 8MB 제한을 안내하고, 삭제 전 확인과 처리 중 중복 실행 방지를 적용한다.

## 콘텐츠 편집 권한
- 공지·논문(학술대회·저널)·모집요강·사진자료실의 등록·수정·삭제 조작과 관리 열은 관리자 세션에서만 노출하고, 공개 화면은 목록·상세 조회와 허용된 다운로드만 제공한다.
- 저장·삭제 중에는 중복 실행과 모달 닫기를 막고, 삭제 전에는 복구 불가 확인 대화상자를 표시한다.
- 네 콘텐츠의 모든 관리 쓰기 API는 서버의 활성 관리자 검증, 동일 출처 검사, 입력 검증과 요청 속도 제한을 모두 통과해야 한다.
- 첨부 업로드 조작도 관리자 세션에서만 제공하며, 공개 방문자는 콘텐츠에 연결된 기존 첨부를 내려받을 수 있다.
- 헤더와 모바일 메뉴에 관리자 로그인·로그아웃·관리자 진입 경로를 제공하고 `/admin`은 실제 관리자 화면을 표시한다.
- 최초 활성 관리자가 없을 때만 일회성 설정 폼을 표시한다. 관리자 활성화 후에는 설정 폼을 제거하고 일반 로그인에는 관리자 아이디와 마스킹된 비밀번호만 요구한다.

- 사진 등록·정보 수정·이미지 추가·순서 변경·이미지 삭제·앨범 삭제 조작은 관리자 로그인 상태에서만 표시하고, 모든 변경 API에서도 활성 관리자 권한을 재검증하도록 구성

- 전체 ZIP 생성을 서버 동시 2건으로 제한하고, 화면 표시용 이미지와 다운로드에 각각 15분당 600회·60회의 별도 제한을 적용하며 ETag 기반 즉시 재검증으로 삭제 사진의 장기 캐시 잔존을 방지
- 공개 사진·다운로드·앨범 ZIP 응답은 Neon 데이터에서 제공해 Render 로컬 디스크 재시작·재배포와 무관하게 유지되도록 분리
- 목록은 데스크톱 3열·좁은 화면 2열로 전환하고, 설명형 대체텍스트·가시적 키보드 포커스·현재 썸네일 상태·동작 감소 설정을 반영
